# Kit externo de marca LinkVentas

Este kit usa exclusivamente el sistema aprobado en
[`BRAND_SYSTEM.md`](./BRAND_SYSTEM.md). Los archivos se exponen desde
`public/brand/` para que puedan descargarse o reutilizarse sin reconstruir el
símbolo.

| Pieza | Archivo | Medida | Uso |
| --- | --- | --- | --- |
| Favicon | `linkventas-favicon-16.png`, `linkventas-favicon-32.png` | 16 y 32 px | Pestañas y marcadores heredados. |
| Icono de aplicación | `linkventas-apple-touch-icon.png` | 180 × 180 px | Atajo en iOS y perfiles que aceptan PNG cuadrado. |
| Avatar | `linkventas-avatar.png` | 1024 × 1024 px | Redes y mensajería; mantener el recorte cuadrado. |
| Portada | `linkventas-cover.svg`, `linkventas-cover.png` | 1584 × 396 px | Portada general; verificar el área segura de cada red antes de publicar. |
| Plantilla de publicación | `linkventas-post-template.svg`, `linkventas-post-template.png` | 1080 × 1080 px | Sustituir sólo los textos de ejemplo por mensajes comprobables. |

## Reglas de aplicación

- Usar el avatar tal cual: no añadir iniciales, sombras ni marcos externos.
- Mantener el azul profundo `#102A4C` como superficie dominante y el azul
  `#2F7EDA` como acento. El verde conserva únicamente significado de éxito.
- La plantilla muestra textos de referencia. Antes de publicar, reemplazar el
  dominio provisional `linkventas.pe` cuando se confirme el dominio comercial.
- El SVG es el original editable para herramientas compatibles; el PNG es la
  exportación lista para cargar. No escalar el favicon como fuente de una pieza
  grande.

## Verificación manual

1. Cargar avatar y portada en cada red de destino y confirmar el área segura.
2. Confirmar el dominio y nombre comercial antes de usar la plantilla sin
   cambios.
3. Abrir los PNG a escala 100 % y validar la legibilidad de la marca antes de
   entregarlos a un tercero.
